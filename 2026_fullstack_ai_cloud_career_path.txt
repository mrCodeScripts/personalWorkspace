I. THE TECHNICAL STACK (The "What")
----------------------------------------------------------------
Master these specific sub-topics to move from "Basic" to "Expert."

1. ADVANCED NEXT.JS & REACT (Frontend/Full-stack)

   CORE FRAMEWORK
   ---------------------------------------------------------------
   - Next.js 15+         The main framework. App Router, Server
                         Components, Server Actions, PPR.
                         Resource: https://nextjs.org/docs

   - React 19            The UI library under Next.js.
                         Resource: https://react.dev

   - TypeScript          Non-negotiable in 2026. Typed code = fewer
                         bugs and easier to sell to serious clients.
                         Resource: https://www.typescriptlang.org/docs

   STYLING & UI COMPONENTS
   ---------------------------------------------------------------
   - Tailwind CSS        Utility-first CSS. Fastest way to style
                         professional UIs without writing raw CSS.
                         Resource: https://tailwindcss.com/docs

   - shadcn/ui           Pre-built, copy-paste components built on
                         Tailwind + Radix. Industry standard for
                         dashboards and SaaS apps.
                         Resource: https://ui.shadcn.com

   - Radix UI            Headless, accessible UI primitives that
                         shadcn/ui is built on. Good to understand
                         the foundation.
                         Resource: https://www.radix-ui.com

   - Framer Motion       Animations and transitions. Makes your apps
                         look polished and premium — clients notice.
                         Resource: https://www.framer.com/motion

   AUTHENTICATION
   ---------------------------------------------------------------
   - Better Auth         Modern, type-safe auth for Next.js. Supports
                         MFA, OAuth (Google, GitHub), and Magic Links.
                         Resource: https://www.better-auth.com/docs

   - Auth.js (NextAuth)  The older but still widely used standard.
                         Worth knowing since many existing codebases
                         use it.
                         Resource: https://authjs.dev

   DATABASE & ORM
   ---------------------------------------------------------------
   - Drizzle ORM         Lightweight, type-safe ORM. Pairs perfectly
                         with Neon and is what most modern Next.js
                         projects use.
                         Resource: https://orm.drizzle.team/docs

   - Prisma              The older, heavier ORM alternative. Still
                         used by many clients — good to know both.
                         Resource: https://www.prisma.io/docs

   - Neon (Postgres)     Serverless Postgres DB. Free tier available.
                         Best pairing for Next.js + Drizzle.
                         Resource: https://neon.tech/docs

   - Supabase            Postgres + Auth + Storage all-in-one.
                         Great for rapid prototyping.
                         Resource: https://supabase.com/docs

   FORMS & VALIDATION
   ---------------------------------------------------------------
   - React Hook Form     The standard for handling forms in React.
                         Performant, minimal re-renders.
                         Resource: https://react-hook-form.com

   - Zod                 Schema validation library. Pair it with
                         React Hook Form to validate inputs properly.
                         Resource: https://zod.dev

   STATE MANAGEMENT
   ---------------------------------------------------------------
   - Zustand             Simple, lightweight global state. Use this
                         instead of Redux — much less boilerplate.
                         Resource: https://docs.pmnd.rs/zustand

   - TanStack Query      Async state management for data fetching,
     (React Query)       caching, and syncing server data.
                         Resource: https://tanstack.com/query/latest

   PAYMENTS
   ---------------------------------------------------------------
   - Stripe              Industry standard for payments. Learn
                         Checkout, Webhooks, and Subscriptions.
                         Resource: https://stripe.com/docs

   - LemonSqueezy        Simpler Stripe alternative. Good for digital
                         products and SaaS subscriptions.
                         Resource: https://docs.lemonsqueezy.com

   EMAIL
   ---------------------------------------------------------------
   - Resend              Modern email API built for developers.
                         Resource: https://resend.com/docs

   - React Email         Build email templates with React components.
                         Pairs with Resend.
                         Resource: https://react.email/docs

   FILE UPLOADS
   ---------------------------------------------------------------
   - UploadThing         The easiest file upload solution for Next.js.
                         Resource: https://docs.uploadthing.com

   ===============================================================
   SHOULD YOU LEARN DESIGN? — YES, BUT KEEP IT PRACTICAL
   ===============================================================
   You don't need to become a UI/UX designer. But you need to
   know enough to build things that don't look ugly, because
   clients judge with their eyes first.

   What to learn:
   - Figma (Free)        Learn the basics: frames, auto-layout,
                         components, and prototyping. Use it to
                         plan your app before coding it.
                         Resource: https://www.figma.com/resources/learn-design
                         YouTube:  "Figma for Developers" by Fireship
                                   https://www.youtube.com/@Fireship

   - Design Fundamentals Learn spacing, typography, color, and
                         contrast. These 4 things alone will make
                         your UIs look 10x more professional.
                         Resource: https://www.refactoringui.com
                                   (Refactoring UI — by Tailwind creators,
                                    highly recommended, paid but worth it)
                         Free alt:  https://www.adhamdannaway.com/blog

   - Copy from the best  Study sites on https://www.awwwards.com and
                         https://dribbble.com. Then rebuild layouts
                         you like using Tailwind + shadcn/ui.

   The shortcut: shadcn/ui + Tailwind already gives you a clean,
   professional baseline. Focus on spacing and typography and you
   will look like a designer without being one.

2. THE AI ENGINEERING LAYER (The Multiplier)
   - LLM Integration
       Master the Vercel AI SDK.
       Learn to switch between OpenAI, Anthropic (Claude), and DeepSeek.
   - RAG (Retrieval-Augmented Generation)
       Embeddings  — converting text into numbers (vectors)
       Vector DBs  — using pgvector inside your existing Neon/Postgres DB
   - AI Agents
       Use LangChain or LlamaIndex to let AI "perform tasks."
       Example: "AI, find the best-selling product and email the
                 report to the boss."

3. DEVOPS & CLOUD (The "Friend's Secret")
   - Docker
       Containerize your app so it runs anywhere.
   - VPS Management
       Set up a $5/mo Linux server (Hetzner / DigitalOcean).
   - Coolify / Dokku
       Self-host your own "Private Vercel" to save clients
       thousands in subscription fees.
   - AWS Basics
       S3          — file storage (images/PDFs)
       IAM         — security
       CloudFront  — speed (CDN)

III. HOW TO SELL & GET CLIENTS (The "Money" Part)
----------------------------------------------------------------
You are broke — you need high-intent, low-cost outreach.

1. THE "DEMO-FIRST" METHOD (High Success)
   The Move:
     Don't ask for a job. Find a business. Build a tiny piece
     of their solution (a landing page or a chatbot).
   The Pitch:
     "Hey, I saw your site doesn't have an AI assistant to handle
      bookings. I built a quick demo of how it would look for you.
      Want to see the link?"
   Result:
     It's 10x harder to say no to a working product than a resume.

2. WHERE TO SHOW YOUR SKILLS
   - Twitter (X) & LinkedIn
       Post "Build-in-Public." Record a 1-minute Loom video of
       a feature you just finished. Tag founders of AI startups.
   - Reddit & Discord
       Go to r/SaaS or r/NextJS. Look for people complaining about
       bugs or high Vercel bills.
       DM them: "I can migrate you to a VPS and save you $100/mo."
   - Upwork (Specialized)
       Do NOT bid on "General Web Dev."
       Only bid on:
         - "Next.js AI Integration"
         - "Drizzle/Prisma Database Migration"

3. THE "₱5K–₱20K" QUICK GIGS (Bread & Butter)
   - Cloud Setup
       Offer to set up Docker/SSL/Linux servers for people who
       only know how to code but are scared of the terminal.
   - Database Fixes
       Offer to migrate someone from a messy MongoDB to a clean,
       typed Drizzle/Postgres setup.

IV. THE "BROKE-TO-PRO" DAILY SCHEDULE
----------------------------------------------------------------
NOTE: There are two phases. Do NOT skip to Phase 2 before
you have at least 1 polished project you can show a client.

PHASE 1 — "GET DANGEROUS" (Weeks 1–6 of your overall journey)
---------------------------------------------------------------
Goal: Build real things. Get fast. Get confident.

   08:00 – 11:00   Deep Work (Build, don't just watch)
                   Follow a project idea but modify it as you go.
                   Use AI to help you build faster — that's fine.

   11:00 – 12:00   Break things on purpose.
                   Try to add one feature the tutorial didn't cover.
                   This is where real learning happens.

   13:00 – 15:00   Read docs or watch ONE focused video.
                   One topic per day only. (e.g. today = Drizzle only)

   15:00 – 16:00   Rebuild what you just learned from scratch.
                   No peeking. If you can't, you don't know it yet.

   16:00 – 17:00   GitHub commit + write 3 sentences about what
                   you learned today. Quietly builds your portfolio.

PHASE 2 — "MONEY MODE" (Once you can ship without tutorials)
---------------------------------------------------------------
You are ready for this phase when you can build a Next.js app
with login, a database, and one feature — without following
a tutorial step by step.

   08:00 – 11:00   Deep Work — Build the client demo or your
                   current portfolio project.

   11:00 – 12:30   Polish and deploy. Every project must be live.
                   A GitHub link is not enough. Clients want a URL.

   13:00 – 15:00   "The Hunt" — Send 5 Demo DMs or apply to
                   5 high-quality Upwork gigs. No generic pitches.

   15:00 – 17:00   Learn one new thing that a client would pay for.
                   (e.g. Stripe integration, AI chatbot, Auth setup)

V. THE 2-WEEK ₱28,000 (~$500) SPRINT PLAN
----------------------------------------------------------------
This is your personalized plan based on your current situation:
- You already know Next.js and can build with AI assistance
- You have one MVP (PubMarket app) as portfolio proof
- You have a classmate who already landed a ₱5K client
- You have no other network yet
- You have 2 weeks

TARGET: ₱28,000 across 2–3 small gigs
REALISTIC BREAKDOWN:
  - 1 simple business landing page       ₱5,000 – ₱8,000
  - 1 slightly bigger site or dashboard  ₱10,000 – ₱15,000
  - 1 extra gig or repeat client         ₱5,000 – ₱8,000
                                         ─────────────────
                               TOTAL     ₱20,000 – ₱31,000 ✓

===============================================================
WEEK 1 — "PREPARE & ATTACK"
===============================================================
Goal: Polish your portfolio, build one demo, land first lead.

DAY 1 (Monday)
   - Open your PubMarket app. List what's broken or unpolished.
   - Fix the top 3 things that would embarrass you if a client
     saw them. Focus on UI — buttons, spacing, mobile layout.
   - Deploy it live if not already. Get a clean URL.
   - Message your classmate: "Pare, how mo nakuha yung client mo?
     Anong ginawa mo?" — Get their exact process. This is gold.

DAY 2 (Tuesday)
   - Pick ONE type of local business to target.
     Best options for fast money in PH:
       * Food businesses / restaurants (need menus, online orders)
       * Salons / nail spas (need booking pages)
       * Small retailers / boutiques (need a simple catalog site)
       * Tutoring / review centers (need landing + enrollment form)
   - Find 10 of these businesses on Facebook or Google Maps.
     Look for ones with: no website, OR a clearly outdated site.
   - List them in a Google Sheet: Name, FB Page, Contact, Notes.

DAY 3 (Wednesday)
   - Build a FAKE demo for one of those business types.
     Example: A landing page for a fictional salon called
     "Glow PH" with a booking section, services list, and
     contact form. Use Next.js + Tailwind + shadcn/ui.
   - This demo is your weapon. It doesn't need a backend.
     It just needs to look real and professional.
   - Deploy it on Vercel. Free. Takes 5 minutes.

DAY 4 (Thursday)
   - Screenshot and screen-record the demo (use Loom, free).
   - Start reaching out to your list of 10 businesses.
     Send this message on Facebook Messenger or via email:

     "Hi! I'm a web developer specializing in Next.js and
      modern websites. I noticed [Business Name] doesn't have
      a website yet (or: your site looks like it could use
      an upgrade). I actually built a quick demo of what a
      modern site could look like for a business like yours.
      Would it be okay if I share the link? No obligation. :)"

   - Send to all 10. Numbers game. Expect 2–4 replies.

DAY 5 (Friday)
   - Follow up on any replies. If they're interested, set a
     quick call (even just a 15-min GCash video call is fine).
   - Set up your Upwork profile. Niche title only:
     "Next.js Developer | Landing Pages & Web Apps"
     Add PubMarket as your portfolio item. Write a short bio
     focused on what you can build for clients, not your skills.
   - Apply to 3 Upwork jobs. Look for: "landing page", "Next.js",
     "simple website." Write a custom proposal for each.

DAY 6 (Saturday)
   - Build a second demo targeting a different business type.
     (e.g. if Day 3 was a salon, now do a tutoring center or
      a small food business.)
   - The more demos you have, the more types of clients you
     can pitch. Treat each demo as a reusable sales asset.

DAY 7 (Sunday)
   - Rest. Seriously. Burnout in week 1 kills week 2.
   - Review: How many replies did you get? Any calls booked?
     Adjust your message if no one replied. The message matters.

===============================================================
WEEK 2 — "CLOSE & COLLECT"
===============================================================
Goal: Convert at least 1–2 leads into paid work.

DAY 8 (Monday)
   - Follow up on every lead from Week 1. One message is not
     enough. People are busy. Follow up once, politely.
   - If your classmate gave you intel, ask them directly:
     "Pwede mo ba ako i-refer sa ibang kilala mo na may business?"
     A warm referral is worth 10 cold DMs.
   - Apply to 3 more Upwork jobs.

DAY 9 (Tuesday)
   - If you have a call booked: prepare a simple script.
     Ask the client:
       1. "What do you want people to do when they visit your site?"
       2. "Do you have a logo and photos ready?"
       3. "When do you need it?"
     Then say: "I can have a first version ready in 3–4 days.
     My rate for a simple site like this is ₱6,000–₱8,000."
   - Collect 50% downpayment before you start. Always.
     GCash is fine. This is standard practice.

DAY 10 (Wednesday)
   - If a client said yes and paid the downpayment: START BUILDING.
     Use your existing demo as the base. Swap in their content.
     This should take 1–2 days max for a simple landing page.
   - If no client yet: send 10 more DMs to a new batch of
     businesses. Expand to a different business type.

DAY 11 (Thursday)
   - Continue building the client project.
   - Keep Upwork proposals going. 3 more today.
   - Ask your classmate again for a referral — be specific:
     "Kilala mo ba may food business o salon na walang website?"

DAY 12 (Friday)
   - Deliver the first version to the client.
     Send via a live Vercel URL. Ask for feedback.
   - Do 1 round of revisions max for the base price.
     Extra revisions = extra charge. Set this expectation early.

DAY 13 (Saturday)
   - Collect the remaining 50% payment upon client approval.
   - Ask for a testimonial: "Pwede ka bang mag-iwan ng review
     or feedback? For my portfolio lang."
   - Start the next lead or next project immediately.

DAY 14 (Sunday)
   - Count what you made. Even ₱6,000–₱8,000 from one gig is
     proof that the system works.
   - List what went wrong and what to improve for week 3.
   - You now have: 1 paid client, 1 testimonial, 2–3 demos,
     an active Upwork profile, and your classmate as a referral
     source. That is a real freelance foundation.

===============================================================
IMPORTANT NOTES FOR THE SPRINT
===============================================================

ON PRICING:
   - Simple landing page (no backend):     ₱4,000 – ₱7,000
   - Landing page + contact form + email:  ₱6,000 – ₱10,000
   - Full site with auth + database:       ₱15,000 – ₱30,000
   - Never go lower than ₱4,000. You'll resent the work.

ON TOOLS DURING THE SPRINT:
   - Use AI (Claude, ChatGPT, Cursor) to build faster.
     This is not cheating. This is how professionals work in 2026.
   - Use Vercel for free deployment. Zero setup time.
   - Use shadcn/ui + Tailwind for fast, clean UI.
   - Use Canva for quick logo mockups if client has none.

ON MINDSET:
   - You don't need to be an expert to charge money.
     You need to solve a problem the client has.
   - A working website beats a perfect one every time.
     Ship it. Fix it after.
   - Your classmate is proof this works in your exact situation.
     Copy their approach before reinventing the wheel.
   - ₱28,000 in 2 weeks is hard but achievable. Even ₱10,000
     in 2 weeks is a win — it proves the model works and you
     can scale it from there.
