/* 
********************************************************************
*                       PubMarket Features & Contents             *
********************************************************************

1️⃣ Public / User Features
------------------------------------------------
Home / Landing Page:
- Banner / carousel (promotions, featured products)
- Category slider (electronics, fashion, groceries, etc.)
- Product lists (featured, best-selling, recommended)
- Search bar (keywords, products, categories)
- Quick access buttons (Cart, Account, Wishlist)

Products Page:
- Full list of products
- Filter by category, price, popularity
- Search within page
- Grid layout for mobile cards

Product Detail Page:
- Product images carousel / zoom
- Product name, price, description
- Stock availability
- Quantity selector
- Add to cart button
- Related products / "You might also like"

Cart Page:
- List of products added
- Edit quantity / remove items
- Total price & subtotal
- Proceed to checkout button

Checkout Page:
- Shipping information form
- Payment placeholder / method selection
- Order summary (products, total, shipping)
- Confirm purchase button

Authentication / Account:
- Login page (email, password)
- Register page (name, email, password)
- Account page: profile info, orders, addresses, payment info, settings
- Logout button

2️⃣ Seller Features
------------------------------------------------
Seller Dashboard:
- Total products sold
- Total orders
- Pending orders

Seller Products:
- List of seller’s products
- Edit / remove product
- Product stats (views, orders if desired)

Add Product:
- Form to add a new product
- Fields: name, price, image URL, optional description
- Confirmation message after adding

3️⃣ Admin Features (optional / for completeness)
------------------------------------------------
Admin Dashboard:
- Overview of total users, total products, orders

Admin Products:
- Manage all products (add / edit / remove)

Admin Users:
- View registered users
- Edit / deactivate accounts

4️⃣ Global Features / Components
------------------------------------------------
- Navbar: logo, cart icon, account icon
- Bottom Nav (mobile-only): Home, Products, Cart, Account
- Search Bar: visible on Home and Products pages
- Category Slider: scrollable list of product categories
- Product Cards: image, name, price, add-to-cart button
- Buttons: primary, secondary, ghost, error/danger
- Cards / Containers: for products, banners, user info

5️⃣ Data / Contents (Sample for Mocking)
------------------------------------------------
- Products: id, name, price, image, description, category
- Users: id, name, email, avatar (optional)
- Cart: userId, productId, quantity
- Orders (optional placeholder): orderId, products[], total, shipping info

6️⃣ Extra / Nice-to-Have Features (if time allows)
------------------------------------------------
- Wishlist / Favorites
- Product sorting (price low→high, popularity)
- Filter by rating / brand
- Promotional banners / discount labels
- Order history / tracking (dummy data for demo)

✅ Summary
- PubMarket is a mobile-first e-commerce platform
- Public users can browse, search, buy, and manage accounts
- Sellers can manage their own products
- Admins can manage users and products
- All data can be mocked for demo, no backend needed
- Components: navbar, bottom nav, product cards, category sliders, forms, buttons
********************************************************************
*/
