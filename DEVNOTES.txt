# 💻 Full Stack Development Setup — Next.js + Express.js

# =========================
# Project Structure
# =========================
# webDev/proj_01/
# ├─ frontend/            # Next.js (React + TypeScript + Tailwind CSS)
# ├─ backend/             # Express.js (Full stack dependencies)
# └─ typescriptpractice/  # Optional TypeScript practice

# =========================
# 1️⃣ Backend (Express.js)
# =========================

# Create backend folder
mkdir webDev\proj_01\backend

# Navigate to backend
cd webDev\proj_01\backend

# Initialize npm project
npm init -y

# Install core dependency
npm install express

# Install additional dependencies for full-stack dev
npm install cors dotenv helmet morgan nodemon mongoose bcryptjs jsonwebtoken

# =========================
# 2️⃣ Frontend (Next.js)
# =========================

# Create frontend directory
mkdir webDev\proj_01\frontend

# Navigate to frontend
cd webDev\proj_01\frontend

# Create Next.js app with default settings
npx create-next-app@latest . --yes

# Install additional dependencies
npm install axios swr

# =========================
# 3️⃣ TypeScript Practice (Optional)
# =========================

# Create TypeScript practice folder
mkdir webDev\proj_01\typescriptpractice

# Navigate to TypeScript folder
cd webDev\proj_01\typescriptpractice

# Initialize npm project
npm init -y

# Install TypeScript and Node.js types
npm install typescript @types/node

# Initialize TypeScript configuration
npx tsc --init

# Build TypeScript (compile to JS)
npm run build

# Run compiled JavaScript
npm start

# =========================
# 4️⃣ Running the Application
# =========================

# Backend
cd webDev/proj_01/backend
npm run dev   # uses nodemon for hot reload

# Frontend
cd webDev/proj_01/frontend
npm run dev   # runs Next.js dev server

# =========================
# Notes
# =========================
# Ports
# Backend: 3001 (configurable via .env)
# Frontend: 3000

# Backend Dependencies & Purpose
# express      → Core server
# cors         → Cross-Origin Requests
# dotenv       → Environment variables
# helmet       → Security headers
# morgan       → Logging HTTP requests
# nodemon      → Hot reload in dev
# mongoose     → MongoDB ORM
# bcryptjs     → Password hashing
# jsonwebtoken → Auth & token handling

# Frontend Dependencies
# axios → HTTP requests
# swr   → Data fetching & caching

# Optional: Tailwind CSS for styling, TypeScript for type safety
# Recommended: Keep frontend and backend dependencies separate to avoid conflicts

===========================================================
MYSQL SERVER SETUP GUIDE (WINDOWS) - NODE / NEXTJS PROJECT
===========================================================

PURPOSE:
This guide documents how to properly install, fix, and run
MySQL Server on Windows without XAMPP, for Node.js / Next.js
projects.

Includes:
- Installation
- Common Errors
- Fixes
- Manual Initialization
- Service Setup
- Login Reset

-----------------------------------------------------------
1. DOWNLOAD & INSTALL
-----------------------------------------------------------

1. Go to:
   MySQL Community Server (Windows)

2. Download:
   mysql-installer-community-8.x.x.msi

3. When asked to login:
   Click: "No thanks, just start my download"

4. During Install:
   - Setup Type: Developer Default (or Server Only)
   - Set Root Password (SAVE IT)
   - Port: 3306 (default)

Finish install.

-----------------------------------------------------------
2. CHECK IF MYSQL COMMAND WORKS
-----------------------------------------------------------

Open CMD / PowerShell:

mysql -u root -p

If NOT recognized:

Use full path:

"C:\Program Files\MySQL\MySQL Server 8.0\bin\mysql.exe" -u root -p

If still fails → PATH not set.

-----------------------------------------------------------
3. COMMON ERROR: CANNOT CONNECT (10061)
-----------------------------------------------------------

ERROR:
Can't connect to MySQL server on 'localhost:3306'

CAUSE:
MySQL Server is NOT running.

Fix:
Start server manually.

-----------------------------------------------------------
4. START SERVER MANUALLY
-----------------------------------------------------------

cd "C:\Program Files\MySQL\MySQL Server 8.0\bin"

Run:

mysqld

Leave terminal open.

Open new CMD:

mysql -u root

-----------------------------------------------------------
5. COMMON ERROR: MISSING DATA DIRECTORY
-----------------------------------------------------------

ERROR:
Failed to set datadir
No such file or directory

CAUSE:
MySQL data folder not created / initialized.

Fix below.

-----------------------------------------------------------
6. FIX: CREATE DATA FOLDER
-----------------------------------------------------------

Go to:

C:\Program Files\MySQL\MySQL Server 8.0\

Create folder:

data

Result:

C:\Program Files\MySQL\MySQL Server 8.0\data

-----------------------------------------------------------
7. INITIALIZE MYSQL SYSTEM TABLES
-----------------------------------------------------------

Open CMD as Administrator.

cd "C:\Program Files\MySQL\MySQL Server 8.0\bin"

Run:

mysqld --initialize-insecure --user=root

This:
- Creates system tables
- Removes password temporarily

-----------------------------------------------------------
8. START SERVER AGAIN
-----------------------------------------------------------

Run:

mysqld

If no "Aborting" error → SUCCESS.

-----------------------------------------------------------
9. LOGIN WITHOUT PASSWORD
-----------------------------------------------------------

Open new CMD:

mysql -u root

If you see:

mysql>

You are connected.

-----------------------------------------------------------
10. SET ROOT PASSWORD
-----------------------------------------------------------

Inside mysql>:

ALTER USER 'root'@'localhost'
IDENTIFIED BY 'YourStrongPassword123';

FLUSH PRIVILEGES;

exit;

Test:

mysql -u root -p

-----------------------------------------------------------
11. INSTALL MYSQL AS WINDOWS SERVICE (PERMANENT FIX)
-----------------------------------------------------------

So MySQL auto-starts with Windows.

Open CMD as Admin:

cd "C:\Program Files\MySQL\MySQL Server 8.0\bin"

Install:

mysqld --install MySQL80

Start:

net start MySQL80

Check:

services.msc → MySQL80

-----------------------------------------------------------
12. RESET PASSWORD (IF FORGOTTEN)
-----------------------------------------------------------

Stop service:

net stop MySQL80

Start insecure:

mysqld --skip-grant-tables

New CMD:

mysql -u root

Reset password:

ALTER USER 'root'@'localhost'
IDENTIFIED BY 'NewPass123';

FLUSH PRIVILEGES;

Restart service.

-----------------------------------------------------------
13. BASIC DATABASE SETUP
-----------------------------------------------------------

Login:

mysql -u root -p

Create DB:

CREATE DATABASE mart_db;

Use DB:

USE mart_db;

Example table:

CREATE TABLE users (
  id INT AUTO_INCREMENT PRIMARY KEY,
  name VARCHAR(100),
  email VARCHAR(100) UNIQUE,
  password VARCHAR(255),
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-----------------------------------------------------------
14. BACKUP & RESTORE DATABASE
-----------------------------------------------------------

Backup:

mysqldump -u root -p mart_db > mart_db.sql

Restore:

mysql -u root -p mart_db < mart_db.sql

-----------------------------------------------------------
15. IMPORTANT NOTES
-----------------------------------------------------------

- Never store raw passwords.
- Always hash in backend.
- MySQL data is NOT stored in project folder.
- Use SQL dump for portability.
- Always remember root password.
- Register service for auto-start.

-----------------------------------------------------------
STATUS:
This setup is tested and working on Windows
for Node.js / Next.js backend development.

AUTHOR: Boss 😎
DATE: 2026

END OF MYSQL SETUP GUIDE
